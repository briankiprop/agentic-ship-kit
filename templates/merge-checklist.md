## Required

- [ ] Plan created

- [ ] Integration tests passed where relevant
- [ ] E2E tests passed where relevant
- [ ] Security checks passed
- [ ] Reviewer approved
- [ ] CI passed
- [ ] Human approved merge

## Block merge if

- [ ] Tests failed
- [ ] Security issue found
- [ ] Scope changed without plan update
- [ ] Secrets exposed
- [ ] Reviewer decision is REQUEST CHANGES or BLOCK
